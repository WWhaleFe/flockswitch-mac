# flockswitch (macOS)

[English](README.md) · **한국어**

마우스 버튼 한 번으로 Logitech 마우스와 **키보드를 함께** 다른 컴퓨터로 넘깁니다.

flockswitch는 MX Master 마우스의 **휠 모드 전환 버튼, 제스처 버튼, 휠 클릭(휠을 눌러 클릭)** 중 고른 버튼을 Easy-Switch 버튼으로 바꿉니다. 누르면 그룹으로 묶은 장치(키보드, 다른 마우스)가 먼저, 마우스가 마지막으로 **같은 Easy-Switch 채널**로 이동합니다. 컴퓨터끼리 네트워크 연결이 필요 없어서 Logitech Flow를 쓸 수 없는 곳(공용 네트워크, 보안이 엄격한 네트워크)에서도 동작합니다.

이 저장소는 macOS 버전입니다. 다른 버전은 [flockswitch-windows](https://github.com/WWhaleFe/flockswitch-windows), [flockswitch-linux](https://github.com/WWhaleFe/flockswitch-linux), [flockswitch-android](https://github.com/WWhaleFe/flockswitch-android)에 있으며, 모두 같은 방식으로 전환되어 섞어 쓸 수 있습니다.

> Logitech과 관계없는 개인 오픈소스입니다. "Logitech", "MX Master", "Easy-Switch", "Bolt", "Unifying"은 Logitech의 상표입니다.

## 지원 마우스

flockswitch는 **MX Master 3**와 **MX Master 4**를 바탕으로 만들고 시험했습니다. 같은 버튼과 기능(HID++ 2.0 *Change Host*, 버튼 재지정)을 가진 다른 Logitech 마우스도 동작할 수 있지만 **아직 시험하지 않았으며**, 추후 시험이 필요합니다. 다른 마우스에서 써 본 결과를 알려 주시면 반영하겠습니다.

## 준비

1. 키보드와 마우스를 각 컴퓨터에 **같은 채널 번호**로 페어링해 둡니다. 예: 채널 1 = 윈도우 PC, 채널 2 = 맥.
2. 오가는 **모든 컴퓨터에 flockswitch를 설치**합니다(Windows PC에는 flockswitch-windows).
3. flockswitch는 Logi Options+와 함께 쓰는 것을 전제로 합니다. 설정하기 전에 Options+에서 사용할 버튼을 **동작 없음**으로 바꿔 두세요. 다른 기능이 할당돼 있으면 그 기능과 전환이 동시에 일어납니다.

## 설치 (Apple Silicon)

[Homebrew](https://brew.sh)를 쓰면:

```sh
brew install --cask wwhalefe/tap/flockswitch
```

`flockswitch.app`이 응용 프로그램 폴더에 설치되고, 터미널에서 `flockswitch` 명령도 쓸 수 있습니다. 업데이트는 `brew update && brew upgrade --cask flockswitch`입니다 (맥에서는 `--cask`가 꼭 필요합니다). 설치와 업데이트가 끝나면 앱이 바로 실행되고, 보안 확인은 필요 없습니다.

flockswitch는 스스로도 업데이트합니다. 시작할 때와 24시간마다 새 버전을 찾으면 내려받아, 릴리스에 함께 올라온 SHA-256 체크섬과 맞는지 확인한 뒤 앱을 바꿔 넣고 다시 시작합니다. 설정 → 일반에서 **새 버전 자동 설치**를 끄면 **지금 업데이트**를 누를 때만 설치합니다 (`set auto_update false`). 앱이 있는 폴더에 쓸 수 없는 등 그 자리에서 바꿀 수 없으면, 지금 업데이트는 새 버전을 다운로드 폴더에 받아 둡니다. Homebrew로 설치했다면 `brew`에는 예전 버전으로 남지만 문제는 없습니다. 다음 `brew upgrade --cask flockswitch` 때 같은 버전을 다시 설치할 뿐입니다.

또는 [Releases](../../releases)에서 내려받습니다.

1. `flockswitch-macos-arm64-<버전>.zip`을 풀고 `flockswitch.app`을 **응용 프로그램** 폴더로 옮김
2. 처음 한 번은 보안 확인이 필요합니다:
   - 앱을 **우클릭 → 열기 → 열기**, 또는
   - 열리지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**
3. 상단 메뉴 막대에 ⇄ 아이콘이 생깁니다. Dock에는 나타나지 않습니다.

## 사용

⇄ 아이콘 메뉴에서 상태 확인, 켜기/끄기, **설정…**, 개발자에게 리포트, 업데이트 확인, 종료를 할 수 있습니다(새 버전이 있으면 "지금 업데이트"도 나타납니다). **설정…**을 누르면 설정 창이 열리고, 체크하는 즉시 적용되며 창은 열린 채로 유지됩니다.

| 탭 | 항목 | 내용 |
|---|---|---|
| 전환 | 마우스 버튼으로 전환 | 켜기/끄기 (끄면 버튼이 원래대로 동작) |
| 전환 | 버튼별 설정 | 휠 모드 전환·제스처·휠 클릭을 각각 켜기/끄기 (여러 개 가능) |
| 전환 | 이동할 채널 (버튼별) | 누르면 고른 채널 하나로 이동. 설정은 컴퓨터마다 따로라 각 컴퓨터에서 고르며, 이 컴퓨터의 채널은 고를 수 없음 |
| 전환 | 제스처 버튼 | 누르기와 누른 채 ↑↓←→ 움직이기, 다섯 가지에 각각 채널 지정 (방향을 켜면 누르는 동안 커서가 멈춤) |
| 전환 | 단축키 | 채널마다 키보드 단축키 하나(기본 ⌃⌥1 / ⌃⌥2 / ⌃⌥3, 바꾸기 가능). 어떤 키보드로 눌러도 그룹 장치와 마스터 마우스가 그 채널로 이동. 이 맥에 연결된 장치만 움직일 수 있어서, 함께 넘어가지 않는 키보드(유선 등)로는 보내기만 되고 데려오기는 다른 컴퓨터에서 해야 함. 추가 권한 불필요 |
| 전환 | 모서리 | 커서를 화면 바깥쪽 가장자리에 대고 잠시(0.3~2초, 선택) 머물면 그 방향에 정한 채널로 그룹 장치와 마스터 마우스가 이동. 네트워크 없이 각 컴퓨터가 자기 화면만 보므로 컴퓨터마다 켜고 각 방향에 그쪽에 있는 컴퓨터의 채널을 지정. 기다리는 동안 커서 근처에 노란색 효과(링·반원·막대·펄스·레이저·보텍스·스캔·리퀴드 중 선택)가 줄어들고, Control을 누른 동안에만 전환하는 옵션도 있음. 마우스가 돌아오면 커서가 보냈던 쪽 가장자리에 나타남. 네 귀퉁이는 제외되고, 모니터가 여러 대면 다른 모니터로 이어지는 가장자리는 전환하지 않음 |
| 장치 | 마스터 마우스 | 버튼을 쓸 마우스 |
| 장치 | 함께 이동할 장치 | Bolt·Unifying·블루투스 장치를 섞어서 선택. 다른 컴퓨터에 가 있는 장치도 표시 |
| 일반 | 진동 (MX Master 4) | 요약과 **진동 설정…** 창: 켜기/끄기, 세기, 상황별 파형, 전환이 가까울수록 강해지는 진동 (모터가 있는 마우스만) |
| 일반 | 마우스 찾기 | 단축키, 다른 컴퓨터에서 도착, 마우스 흔들기로 커서 주변에 펄스 링·레이더·스포트라이트 표시 |
| 일반 | 시작하기 전에 | Options+에서 사용할 버튼을 "동작 없음"으로 바꾸라는 안내 |
| 일반 | 업데이트 | 새 버전 확인(자동/지금), 자동 설치 또는 지금 업데이트(SHA-256 확인 후 설치하고 다시 시작) |
| 일반 | 개발자에게 | 메일 앱 열기(버전·장치 정보 자동 기입), 주소 복사, GitHub 신고 |
| 일반 | 언어 | 한국어 / English (처음에는 컴퓨터 언어를 따름) |
| 일반 | 로그인 시 자동 실행 | 켜기/끄기 |
| 일반 | 제거 | 버튼 원래대로, 자동 실행 해제, 설정 삭제 후 종료 |

설정 창이 다른 창 뒤에 가려져 있어도 메뉴에서 **설정…**을 다시 누르면 맨 앞으로 나옵니다. flockswitch를 끄거나 버튼을 끄면 그 버튼은 원래 상태(Options+ 설정 포함)로 돌아갑니다.

명령줄: `/Applications/flockswitch.app/Contents/MacOS/flockswitch help`

설정 위치: `~/Library/Application Support/flockswitch/`

## 제거

1. ⇄ 메뉴 → **설정…** → 맨 아래 **flockswitch 제거…** → **제거**. 버튼을 원래대로 돌려놓고, 자동 실행을 해제하고, 설정 폴더를 지운 뒤 종료합니다.
2. `flockswitch.app`을 지웁니다. Homebrew로 설치했다면 `brew uninstall --cask flockswitch`.

드라이버나 서비스를 설치하지 않고 시스템 설정도 바꾸지 않습니다.

## 개인정보

flockswitch는 이 맥에 연결된 Logitech 장치와 통신합니다. 인터넷 연결은 GitHub에서 새 버전이 있는지 확인할 때(시작할 때와 하루 한 번, 설정 → 일반에서 끌 수 있음)와 버튼을 눌러 내려받을 때뿐이며, 사용자나 장치에 대한 정보는 보내지 않습니다. "개발자에게 리포트"는 사용자의 메일 앱을 열 뿐이라 보내기 전에 내용을 모두 확인할 수 있습니다. (중복 실행을 막으려고 `127.0.0.1`의 포트 하나를 잡아 둘 뿐, 그 포트로 주고받는 데이터는 없습니다.)

## 문제가 생기면

⇄ 메뉴 → **개발자에게 리포트…**(또는 설정 → 일반)로 메일을 보내거나, [문제 신고](../../issues/new/choose) 양식에 아래를 붙여 주세요.

- 명령줄의 `flockswitch list` 결과
- macOS 버전, 연결 방식(Bolt / Unifying / 블루투스), 장치 이름
