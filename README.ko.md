# flockswitch (macOS)

[English](README.md) · **한국어**

## 2.0: 네트워크 공유와 Logitech 전환

flockswitch 2.0은 신뢰할 수 있는 로컬 네트워크에서 내 컴퓨터끼리 마우스·키보드·클립보드(글·이미지·파일)를 공유합니다. 네트워크 설정에서 마스터를 선택하고 같은 인증 번호를 확인해 서브를 최대 3대 연결한 다음 화면 위치를 배치합니다. 입력은 인증된 TLS 1.3 연결로 전송합니다. 맥에서는 손쉬운 사용과 입력 모니터링 권한이 필요합니다. 네트워크 공유는 기본으로 꺼져 있으며 주의 사항에 동의한 뒤 켤 수 있습니다.

새 설정 화면에서도 Logitech Easy-Switch 버튼·채널·단축키·휠 모드·진동·커서 효과를 유지합니다. 화면 모서리는 한 방식이 담당합니다. 네트워크 공유를 켜면 Logitech 모서리 전환이 꺼지고, Logitech 모서리 전환을 켜면 네트워크 모서리 넘기기가 멈춥니다. 버튼과 단축키 전환은 계속 사용할 수 있습니다.

**2.1**에서는 컴퓨터를 실제 책상처럼 놓는 배치 지도(서브끼리 나란히 놓으면 서로 바로 넘어갑니다), 컴퓨터별 "이 컴퓨터의 마우스·키보드로 다른 컴퓨터 쓰기" 스위치, 서브끼리 클립보드 공유, 운영체제 쌍별 키 규칙(네트워크 → 키보드: 보조키 대응, 한/영 키, 한자, 이동 키, 화면 캡처), **연결 다시 찾기**, 잠자기·잠금 해제 뒤 자동 재연결이 추가됐습니다. 설정 창은 크기가 고정된 하나의 창이며 왼쪽에 사이드바가 있습니다.

2.0은 기존 `flockswitch.app`을 대체하며 `~/Library/Application Support/flockswitch/`의 설정, `flockswitch` 로그인 항목, 기존 GitHub 업데이트 경로를 이어 씁니다. 백업은 `~/Documents/flockswitch`에 그대로 둡니다. 기존 앱과 같은 응용 프로그램 위치에 설치하세요. 고정 서명으로 전환하는 첫 업데이트에는 맥 권한을 다시 허용해야 할 수 있으며 설정의 권한 복구 기능을 이용할 수 있습니다. 로컬 네트워크 입력은 연결한 컴퓨터 사이에서만 전송됩니다. [PRIVACY.md](PRIVACY.md)를 참고하세요.

아래의 Logitech 채널 전환 방식은 네트워크 공유와 별도로 계속 사용할 수 있습니다.

마우스 버튼 한 번으로 Logitech 마우스와 **키보드를 함께** 다른 컴퓨터로 넘깁니다.

flockswitch는 MX Master 마우스의 **휠 모드 전환 버튼, 제스처 버튼, 휠 클릭(휠을 눌러 클릭)** 중 고른 버튼을 Easy-Switch 버튼으로 바꿉니다. 누르면 그룹으로 묶은 장치(키보드, 다른 마우스)가 먼저, 마우스가 마지막으로 **같은 Easy-Switch 채널**로 이동합니다. 컴퓨터끼리 네트워크 연결이 필요 없어서 Logitech Flow를 쓸 수 없는 곳(공용 네트워크, 보안이 엄격한 네트워크)에서도 동작합니다.

이 저장소는 macOS 버전입니다. 다른 버전은 [flockswitch-windows](https://github.com/WWhaleFe/flockswitch-windows), [flockswitch-linux](https://github.com/WWhaleFe/flockswitch-linux), [flockswitch-android](https://github.com/WWhaleFe/flockswitch-android)에 있으며, 모두 같은 방식으로 전환되어 섞어 쓸 수 있습니다.

> Logitech과 관계없는 개인 오픈소스입니다. "Logitech", "MX Master", "Easy-Switch", "Bolt", "Unifying"은 Logitech의 상표입니다.

## 지원 마우스

flockswitch는 **MX Master 3**와 **MX Master 4**를 바탕으로 만들고 시험했습니다. 같은 버튼과 기능(HID++ 2.0 *Change Host*, 버튼 재지정)을 가진 다른 Logitech 마우스도 동작할 수 있지만 **아직 시험하지 않았으며**, 추후 시험이 필요합니다. 다른 마우스에서 써 본 결과를 알려 주시면 반영하겠습니다.

## 준비

1. 키보드와 마우스를 각 컴퓨터에 **같은 채널 번호**로 페어링해 둡니다. 예: 채널 1 = 윈도우 PC, 채널 2 = 맥.
2. 오가는 **모든 컴퓨터에 flockswitch를 설치**합니다(Windows PC에는 flockswitch-windows).
3. flockswitch는 Logi Options+와 함께 쓰는 것을 전제로 합니다. 설정하기 전에 Options+에서 사용할 버튼을 **동작 없음**으로 바꿔 두세요. 다른 기능이 할당돼 있으면 그 기능과 전환이 동시에 일어납니다.

## 설치 (Apple Silicon)

[Homebrew](https://brew.sh)를 쓰면:

```sh
brew install --cask wwhalefe/tap/flockswitch
```

`flockswitch.app`이 응용 프로그램 폴더에 설치되고, 터미널에서 `flockswitch` 명령도 쓸 수 있습니다. 업데이트는 `brew update && brew upgrade --cask flockswitch`입니다 (맥에서는 `--cask`가 꼭 필요합니다). Homebrew 6 이상에서 `Refusing to load … from untrusted tap wwhalefe/tap` 오류가 나면 한 번만 `brew trust --cask wwhalefe/tap/flockswitch`를 실행하세요. 설치와 업데이트가 끝나면 앱이 바로 실행되고, 보안 확인은 필요 없습니다.

flockswitch는 스스로도 업데이트합니다. 시작할 때와 24시간마다 새 버전을 찾으면 내려받아, 릴리스에 함께 올라온 SHA-256 체크섬과 맞는지 확인한 뒤 앱을 바꿔 넣고 다시 시작합니다. 설정 → 일반에서 **새 버전 자동 설치**를 끄면 **지금 업데이트**를 누를 때만 설치합니다 (`set auto_update false`). 설정 창이나 ⇄ 메뉴의 **지금 확인**은 확인만 하고, 새 버전이 있으면 나타나는 **지금 업데이트**는 이 설정과 상관없이 백그라운드에서 설치합니다. 앱이 있는 폴더에 쓸 수 없는 등 그 자리에서 바꿀 수 없으면, 지금 업데이트는 새 버전을 다운로드 폴더에 받아 둡니다. Homebrew로 설치했다면 `brew`에는 예전 버전으로 남지만 문제는 없습니다. 다음 `brew upgrade --cask flockswitch` 때 같은 버전을 다시 설치할 뿐입니다.

또는 [Releases](../../releases)에서 내려받습니다.

1. `flockswitch-macos-arm64-<버전>.zip`을 풀고 `flockswitch.app`을 **응용 프로그램** 폴더로 옮김
2. 처음 한 번은 보안 확인이 필요합니다:
   - 앱을 **우클릭 → 열기 → 열기**, 또는
   - 열리지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**
3. 상단 메뉴 막대에 ⇄ 아이콘이 생깁니다. Dock에는 나타나지 않습니다.

## 사용

⇄ 아이콘 메뉴에서 상태 확인, 켜기/끄기, **설정…**, 개발자에게 리포트, 업데이트 확인, 종료를 할 수 있습니다(새 버전이 있으면 "지금 업데이트"도 나타납니다). **설정…**을 누르면 크기가 고정된 설정 창이 열립니다. 왼쪽 사이드바에서 페이지를 고르고, 페이지가 창보다 길면 창 안에서 스크롤합니다. 바꾸는 즉시 적용되며 창은 열린 채로 유지됩니다. 사이드바 아래 카드에는 마우스가 어디 있는지(연두색 점은 이 맥에 있다는 뜻), 네트워크 상태, 마스터 마우스가 표시됩니다.

| 페이지 | 항목 | 내용 |
|---|---|---|
| 네트워크 > 연결과 배치 | 공유와 역할 | 네트워크 공유 스위치(주의 사항 동의 뒤), 이 컴퓨터의 역할(짝이 없을 때만 마스터/서브 변경) |
| 네트워크 > 연결과 배치 | 짝 맺기 | 같은 6자리 숫자 확인, 근처 컴퓨터, IP로 추가, 짝 맺은 컴퓨터(연결 상태·지연, 그 컴퓨터의 마우스·키보드로 다른 컴퓨터 쓰기 스위치, 해제, 잠시 연결 안 함: 짝은 두고 연결만 멈추며 흐리게 표시) |
| 네트워크 > 연결과 배치 | 배치 지도 | 6 x 4 칸, 모니터마다 한 칸(칸을 누른 뒤 빈 칸을 눌러 그 모니터를 옮김). 마스터는 컴퓨터를 누른 뒤 빈 칸을 눌러 옮기고, 서브끼리 붙여 두면 서로 바로 넘어감. 서브는 마스터가 정한 배치를 잠긴 채로 봄 |
| 네트워크 > 연결과 배치 | 연결 다시 찾기 | 끊긴 연결을 바로 다시 찾음. 잠자기나 잠금에서 돌아오면 자동으로도 다시 연결 |
| 네트워크 > 연결과 배치 | macOS 권한, 백그라운드 | 손쉬운 사용·입력 모니터링 허용 상태와 "권한 다시 받기", 백그라운드 앱이 꺼졌을 때 "다시 시작" |
| 네트워크 > 넘기기 | 넘김 대기 시간, Control, 도착 표시 | 대기 시간(없음~2초, 그동안 효과의 카운트다운), Control을 누른 채 밀 때만 넘기기, 도착하면 커서 위치 표시, 돌아오기 단축키 ⌃⌥⇧Q |
| 네트워크 > 키보드 | OS 전환 시 | 운영체제 쌍(맥과 Windows·Linux·Android)과 방향마다 보조키 기준(기능·자리·바꾸지 않음)과 키별 대응표, 한/영 전환 키(여러 개)와 받는 쪽 키, Caps Lock 길게 누르기, 한자 키, 이동과 편집 키 4가지, 화면 캡처 단축키. 서브에서 바꾸면 마스터에 전달. **운영체제별 키 비교** 창, 키 호환 안내(Shift+Space는 기본으로 어느 컴퓨터에서든 한/영 전환). 2.0의 Cmd/Ctrl·Caps Lock·Shift+Space·한/영 키 스위치는 이 규칙으로 옮겨졌고 기존 설정은 그대로 이어짐 |
| 네트워크 > 클립보드 | 클립보드 | 글·이미지·파일 공유, 서브끼리 공유(마스터를 거쳐 전달), 받은 폴더와 최근 받은 파일, 전송 상태 |
| 네트워크 > 이 컴퓨터 | 이름·포트 | 역할 표시(바꾸기는 연결과 배치에서), 이름, 포트, 이 컴퓨터의 IP, 기기 ID |
| 로지텍 > 버튼 전환 | 마우스 버튼으로 전환 | 켜기/끄기 (끄면 버튼이 원래대로 동작) |
| 로지텍 > 버튼 전환 | 버튼별 채널 | 휠 모드 전환·제스처·휠 클릭 각각, 누르면 고른 채널 하나로 이동. 설정은 컴퓨터마다 따로라 각 컴퓨터에서 고르며, 이 컴퓨터의 채널은 고를 수 없음 |
| 로지텍 > 버튼 전환 | 제스처 버튼 | 누르기와 누른 채 ↑↓←→ 움직이기, 다섯 가지에 각각 채널 지정 (방향을 켜면 누르는 동안 커서가 멈춤) |
| 로지텍 > 버튼 전환 | 돌아오면 휠 모드 되돌리기 | 휠 모드 전환 버튼으로 전환할 때, 마우스가 돌아오면 이 컴퓨터에서 쓰던 휠 모드(걸림·무한 회전)로 되돌림 (기본 켜짐, `set keep_wheel_mode`). 다른 기기에 막 도착해 버튼을 아직 가져가기 전에 누르면 휠 모드가 바뀌기 때문 |
| 로지텍 > 단축키 전환 | 단축키 | 채널마다 키보드 단축키 하나(기본 ⌃⌥1 / ⌃⌥2 / ⌃⌥3, 바꾸기 가능). 어떤 키보드로 눌러도 그룹 장치와 마스터 마우스가 그 채널로 이동. 이 맥에 연결된 장치만 움직일 수 있어서, 함께 넘어가지 않는 키보드(유선 등)로는 보내기만 되고 데려오기는 다른 컴퓨터에서 해야 함. 추가 권한 불필요. ⌃·⌥·⌘(⇧ 추가 가능)과 숫자·글자, 또는 F키만 쓸 수 있고, macOS가 쓰는 조합(⌘Q·⌘W·⌘H·⌘M·⌘⇧3/4/5 등)은 받지 않으며, 다른 앱이 쓰는 조합은 알려 줌. 제목 옆 ⓘ에 정리 |
| 로지텍 > 모서리 전환 | 모서리 | 커서를 화면 바깥쪽 가장자리에 대고 잠시(0.3~2초, 선택) 머물면 그 방향에 정한 채널로 그룹 장치와 마스터 마우스가 이동. 네트워크 없이 각 컴퓨터가 자기 화면만 보므로 컴퓨터마다 켜고 각 방향에 그쪽에 있는 컴퓨터의 채널을 지정. 기다리는 동안 커서 근처에 효과(효과 페이지에서 링·반원·막대·펄스·레이저·보텍스·스캔·리퀴드·랜덤 중 선택)가 줄어들고, 효과마다 색상·크기와 방향(링·반원·막대)·작아지며 사라지기(링·반원)를 따로 정함. 랜덤은 매번 다른 효과를 그 효과의 색상·크기로, 방향과 사라지는 방식은 무작위로 보여 줌. Control을 누른 동안에만 전환하는 옵션도 있음. 마우스가 돌아오면 커서가 보냈던 쪽 가장자리에 나타남. 네 귀퉁이는 제외되고, 모니터가 여러 대면 다른 모니터로 이어지는 가장자리는 전환하지 않음 |
| 로지텍 > 장치 | 마스터 마우스 | 버튼을 쓸 마우스 |
| 로지텍 > 장치 | 함께 이동할 장치 | Bolt·Unifying·블루투스 장치를 섞어서 선택. 다른 컴퓨터에 가 있는 장치도 표시 |
| 앱 > 효과 | 대기 효과 | 넘어가기 전 카운트다운(효과·색상·크기 등) |
| 앱 > 효과 | 마우스 찾기 | 단축키, 다른 컴퓨터에서 도착, 마우스 흔들기로 커서 주변에 펄스 링·레이더·스포트라이트 표시. 흔들기는 0.5~2초 동안 쉬지 않고 흔들어야 하며, ⌃·⌥·⇧·⌘ 중 하나를 누른 채 흔들 때만 반응하게 할 수 있음. macOS의 커서 확대와 flockswitch 강조가 함께 보임 |
| 앱 > 효과 | 진동 (MX Master 4) | 요약과 **진동 설정…** 창: 켜기/끄기, 세기, 상황별 파형, 전환이 가까울수록 강해지는 진동 (모터가 있는 마우스만) |
| 앱 > 일반 | 시작하기 전에 | Options+에서 사용할 버튼을 "동작 없음"으로 바꾸라는 안내(로지텍 > 버튼 전환 페이지) |
| 앱 > 일반 | 업데이트 | 새 버전 확인(자동/지금), 새 버전이 알려지면 **지금 업데이트**(SHA-256 확인 후 설치하고 바로 다시 시작), 자동 설치 |
| 앱 > 일반 | 개발자에게 | 메일 앱 열기(버전·장치 정보 자동 기입), 주소 복사, GitHub 신고 |
| 앱 > 일반 | 설정 백업 | 저장(`~/Documents/flockswitch/flockswitch-settings-<컴퓨터 이름>-<날짜-시각>.toml`), 불러오기(그 폴더의 파일을 최근 순으로 보여 주고, 확인하면 모든 설정을 바꿈), 관리(이름 바꾸기, 삭제 - 휴지통으로), 폴더 열기. 10개까지 저장(폴더의 .toml 파일을 모두 세며 3/10처럼 표시)하고, 10개면 관리에서 정리한 뒤 저장. 파일은 macOS·Windows·Linux가 같아서 다른 컴퓨터의 문서/flockswitch 폴더로 옮겨 불러올 수 있음. 그 컴퓨터에 없는 설정은 건너뛰고, flockswitch 설정 파일이 아니면 거부. 채널은 컴퓨터마다 다르니 불러온 뒤 확인 |
| 앱 > 일반 | 언어 | 한국어 / English (처음에는 컴퓨터 언어를 따름) |
| 앱 > 일반 | 로그인 시 자동 실행 | 켜기/끄기 |
| 앱 > 일반 | 초기화와 제거 | 설정 초기화, 버튼 원래대로, 자동 실행 해제, 설정 삭제 후 종료 |

설정 창이 다른 창 뒤에 가려져 있어도 메뉴에서 **설정…**을 다시 누르면 맨 앞으로 나옵니다. flockswitch를 끄거나 버튼을 끄면 그 버튼은 원래 상태(Options+ 설정 포함)로 돌아갑니다.

명령줄: `/Applications/flockswitch.app/Contents/MacOS/flockswitch help`

설정 위치: `~/Library/Application Support/flockswitch/`

## 제거

1. ⇄ 메뉴 → **설정…** → 맨 아래 **flockswitch 제거…** → **제거**. 버튼을 원래대로 돌려놓고, 자동 실행을 해제하고, 설정 폴더를 지운 뒤 종료합니다.
2. `flockswitch.app`을 지웁니다. Homebrew로 설치했다면 `brew uninstall --cask flockswitch`.

드라이버나 서비스를 설치하지 않고 시스템 설정도 바꾸지 않습니다.

## 개인정보

flockswitch는 연결된 Logitech 장치와 통신하며 네트워크 공유를 켜면 연결한 내 컴퓨터와 로컬 네트워크로 통신합니다. 입력과 클립보드는 인증된 TLS 1.3 연결로 전송합니다. 자동 인터넷 통신은 GitHub 업데이트 확인과 다운로드뿐이며 설정 → 일반에서 자동 확인을 끌 수 있습니다. 사용 통계를 수집하지 않습니다. "개발자에게 리포트"는 메일 앱을 열어 보내기 전에 내용을 확인할 수 있습니다. [PRIVACY.md](PRIVACY.md)를 참고하세요.

## 문제가 생기면
